# Cookie Clicker

A simple Cookie Clicker game written in Python. Click the cookie to earn points, and watch your score grow as you play.

## Features

- Click the cookie to earn cookies
- Live score display
- Simple, single-file project that is easy to read and extend

## Requirements

- Python 3.8 or newer
- No extra libraries are needed beyond the Python standard library (Tkinter ships with the standard Windows and macOS installers)

## Run locally

```bash
git clone https://github.com/jivasnider/Cookie-Clicker-Project.git
cd Cookie-Clicker-Project
python main.py
```

On macOS/Linux you may need to use `python3 main.py` instead.
